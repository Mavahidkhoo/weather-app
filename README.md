# Weather App 🌤️

A **responsive weather application** built with **Tailwind CSS** and **JavaScript**, allowing users to search for cities, view detailed forecasts, and convert between Celsius and Fahrenheit using the [Open-Meteo API](https://open-meteo.com/).

Repository: [https://github.com/Mavahidkhoo/weather-app.git](https://github.com/Mavahidkhoo/weather-app.git)

---

## Features ✅

- **City search**: Find weather for any city.
- **Responsive design**: Works on mobile, tablet, and desktop devices.
- **Unit conversion**: Toggle between Celsius and Fahrenheit.
- **Detailed forecasts**: Temperature, wind speed, humidity, and more.
- **Clean UI with Tailwind CSS**: Modern and user-friendly interface.

---

## Technologies Used 🛠️

- **HTML5 & CSS3**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **Open-Meteo API** for weather data
