# Weather App 🌤️

A **responsive weather application** built with **Tailwind CSS** and **JavaScript**, allowing users to search for cities, view detailed forecasts, and convert between Celsius and Fahrenheit using the [Open-Meteo API](https://open-meteo.com/).

🔗 **Repository**: [weather-app](https://github.com/Mavahidkhoo/weather-app.git)

---

## Features ✅

- **City search**: Find weather for any city worldwide.
- **Responsive design**: Optimized for mobile, tablet, and desktop devices.
- **Unit conversion**: Toggle between Celsius and Fahrenheit.
- **Detailed forecasts**: Get temperature, wind speed, humidity, and more.
- **Fallback UI**: If no image/icon is available, a default color is displayed.
- **Clean UI with Tailwind CSS**: Modern and user-friendly interface.

---

## Technologies Used 🛠️

- **HTML5 & CSS3**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **Open-Meteo API** for weather data
- **Icons & Images** for seasons and weather conditions
